# 工业表面缺陷检测与分割：设计

日期：2026-09-23

## 目标与来源

基于公开 U-Net 分割方法，实现一个可复现的工业缺陷项目。采用数据作者公开的 Magnetic Tile Defect 数据集（MTD），包含正常磁瓦、五类表面缺陷及像素标注。项目不复制教程代码，不把原作者的模型成果写成个人成果。

## 范围

1. 从数据作者仓库获取原始数据；记录来源、版本、样本数和文件校验信息。原始数据不随项目分发。
2. 按原始图片做固定随机种子且类别分层的训练、验证、测试划分；同一图片及其标注只能在一个集合。
3. 实现 OpenCV 阈值与形态学基线，以及轻量 U-Net；采用同一测试集比较。
4. 仅使用验证集选择分割阈值、训练轮次和参数；测试集一次性报告像素 Dice、IoU、图像检测指标及逐类结果。
5. 保存预测掩码、叠加图、失败样例、运行配置和机器可读报告。提供从数据准备到复现结果的中文学习说明。

## 结构与数据流

`prepare` 校验图像与掩码并生成 manifest → `split` 生成固定数据划分 → `train` 用训练集拟合 U-Net 并依验证集保存最佳权重 → `evaluate` 读取最佳权重并对未见测试集计算指标 → `visualize` 导出覆盖图和错误样例。基线通过同一数据加载与评估模块。

数据、模型、评估和可视化分为独立模块。每次运行输出配置、随机种子、数据清单哈希、指标和耗时，避免无法追溯的数字。

## 核验标准

- 数据路径、掩码、划分和指标的关键边界条件有自动化检查。
- 实际完成至少一次基线与 U-Net 的训练和测试，保留原始报告及可查看的结果图。
- 简历只记录真实运行过的任务、方法和指标；不宣称新算法或生产部署。
