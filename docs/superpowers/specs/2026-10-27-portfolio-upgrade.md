# 磁瓦项目升级设计（用户于 2026-10-27 确认）

目标：从固定训练脚本升级成可复现训练、独立图像预测和可解释报告组成的实验工具。保留原版0.575结果。

1. 保留轻量U-Net；新增ImageNet预训练ResNet18编码器的分割模型，更高输入分辨率与成对数据增强。使用独立GPU环境，原CPU环境保持可用。
2. 训练命令只读取训练/验证集，按验证指标选择权重与阈值。原固定940/202/202名单不变，测试集不用于选配置。显式evaluate命令才输出最终测试成绩，记录模型、种子、软件版本、硬件、名单和模型哈希。
3. 新增可信本地权重的单图/文件夹预测：原尺寸概率图、掩码、叠加图、区域面积/边框、JSON汇总。输入和输出路径冲突须拒绝，Unicode路径可用。
4. 新增HTML数值评估报告（指标、逐类结果、与原版比较）；数据派生图、权重、原数据不上传GitHub。
5. 先测模型形状、增强对齐、权重往返、预测尺寸与错误输入；再真实训练。指标提升仅据同口径最终报告陈述，不预设成绩。
