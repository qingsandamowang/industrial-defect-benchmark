# 工业表面缺陷检测与分割实施计划

**目标：** 基于公开真实数据，交付可复现的工业缺陷分割与检测项目及真实测试报告。

**架构：** 数据校验、分层划分、OpenCV 基线、U-Net 训练、统一评估和可视化分别封装。验证集负责模型选择，测试集只用于最终结果。

**技术：** Python、PyTorch、OpenCV、NumPy、scikit-learn。

## 任务

- [x] 获取作者原始 MTD 数据并核查图片/掩码命名、数量、尺寸与来源。
- [x] 先写数据配对和划分的失败测试，再实现 `data.py`；生成固定 manifest。
- [x] 先写 Dice、IoU、图像级指标的失败测试，再实现 `metrics.py`。
- [x] 实现并验证 OpenCV 阈值/形态学基线，保存测试集报告。
- [x] 先写模型张量形状与前向传播测试，再实现轻量 U-Net。
- [x] 实现确定性训练、验证集阈值选择、最佳权重存储和恢复。
- [x] 在同一未见测试集运行 U-Net，保存逐类指标、推理时延和错误样例。
- [x] 写中文学习说明、结果解释和复现步骤，核对简历表述。

## 完成条件

有可执行源码、明确的数据来源、训练权重、真实测试报告、可查看预测图，以及只基于报告撰写的简历内容。
